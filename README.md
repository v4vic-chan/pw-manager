# 🛡️ V4Vault 軍用級隨身密碼管理器 V1.0

一個完全屬於你自己、資料絕不上傳的密碼管理工具。無需安裝，無需任何雲端帳號，不存放資料於 server，不怕被駭。

***

## 🌟 與別不同的極致安全邏輯

- **伺服器不接觸任何資料**：所有密碼與帳號資料，全部存放在你當前使用的手機或電腦瀏覽器專屬保險庫（IndexedDB），伺服器完全不經手，就算被駭都與你無關。
- **軍用 / 銀行級加密**：採用高強度密碼學運算（Argon2id 與 AES-GCM），就算手機或備份資料被別人拿到，只要沒有你設定的主密碼，任何人看到的都只是一堆無法解密的亂碼。
- **支援手機 2FA 驗證**︰支援 2FA，多一重保障。且不設 email 重設主密碼，免除潛在被駭風險。
- **物理阻隔外人強行登入**：由於所有資料存放在你當前使用的手機或電腦瀏覽器，所以除你自己之外，沒有人能接觸你的資料庫。

## 🛠️ 主要功能一覽

### 1. 條目管理
- **直覺新增與編輯**：輕鬆記錄網站名稱、帳號與密碼。
- **密碼防偷窺**：畫面上預設以黑點遮蔽，只有點擊眼睛圖示時才會暫時顯示。
- **一鍵安全複製**：點擊即可複製密碼；剪貼簿具備保護機制，貼上後一段時間會自動清空，防止被其他軟體窺探。
- **隨機密碼產生器**：內建亂數產生器，一鍵產出長達 20 字的高強度安全密碼。

### 2. 分類與搜尋
- **即時搜尋**：輸入關鍵字，清單立即過濾出對應的條目名稱或帳號。
- **自訂分類標籤**：可依生活、工作、金融等自訂分類，並能隨意調整前後順序。
- **貼心防呆設計**：預設的「未分類」不可刪除；若刪除某個自訂分類，裡面的條目會自動移至未分類，資料絕不遺失。

### 3. 進階安全防護
- **雙重驗證 (2FA)**：支援標準 TOTP 驗證器（如 Google Authenticator、1Password），多一層保障。
- **緊急救援碼**：啟用 2FA 時自動產生一次性救援碼，即使驗證器遺失也能安全自救。
- **自動閒置鎖定**：離開座位一段時間未操作，系統會自動重新鎖定，必須輸入主密碼才能解開。
- **密碼錯輸入防護**：連續多次輸錯主密碼會自動觸發等待倒數，防止有心人士暴力破解。

### 4. 備份與還原
- **加密匯出**：隨時將全密碼庫打包成加密檔案下載到自己電腦存放。
- **隨處還原**：換新手機或新電腦時，只要匯入該備份檔並輸入原主密碼，就能立即把密碼庫完整帶過來。

## 📱 適合在哪些環境使用？

任何現代裝置，只要有常見的瀏覽器即可流暢使用：

- **智慧型手機**：iPhone (Safari)、Android (Chrome、Firefox)
- **電腦設備**：Windows、macOS、Linux (Chrome、Edge、Safari、Brave 等)
- **室外隨身用**：直接在手機瀏覽器打開網址即可使用。在 Safari 點選「分享」→「加入主畫面」，或在 Chrome 點選「安裝 / 加到主畫面」，就能像一般手機 App 一樣從桌面單擊啟動。

***

## 🚀 第一次使用指南（只需 3 步驟）

1. **建立保險庫**：初次打開網址，請為自己設定一組至少 12 字元的「主密碼」（請務必牢記，這是解鎖整個密碼庫的唯一鑰匙）。
2. **開始存入帳號**：點擊「新增條目」，輸入條目名稱、帳號與密碼，按下儲存。
3. **❗️重要❗️建立備份**：新增完一批重要密碼後，務必到「安全設定」點選「匯出加密備份」，將備份檔儲存在自己信任的隨身碟或雲端硬碟中（異地備份），建議不要放在當前使用的裝置。

***

## ⭕️ 重要提醒

- **❗️重要❗️妥善保管主密碼**：請務必妥善保管你的主密碼，建議在現時使用的裝置及儲存備份的裝置之外，另選雲端硬碟或本地裝置，分開作異地儲存。如遺失主密碼，即使有備份，整個密碼庫亦將無法復原！
- **更換瀏覽器或裝置**︰主帳號及密碼庫儲存在瀏覽器的專屬儲存位置，所以即使是同一裝置，如更換瀏覽器的話，必須在新瀏覽器匯入備份資料，才可繼續使用既有密碼庫。同理，更換裝置亦必須進行匯入，換言之，你的手機和電腦是不互通 / 不同步的，在一邊操作過密碼庫之後，如要在另一邊打開，必須進行匯出 / 匯入動作才可，請留意。
- **重設瀏覽器**︰跟上述情況一樣，重設瀏覽器後，必須重新匯入備份資料，才可繼續使用既有密碼庫。
- **確保網絡暢通**︰使用本系統必須有網絡連接，請確保網絡暢通。
- **免責聲明**︰如因使用本系統引致任何密碼遺失或實際損失，皆與開發者無關，有關責任用戶需自行承擔。
